<p><b>Scale pivot</b> — World-space point the scale is applied about.</p>
<p><span style='color:#90caf9;'>World origin</span> — scale about (0, 0, 0). Positions move toward / away from the world origin (default).</p>
<p><span style='color:#90caf9;'>Selection</span> — scale about the active object's world-space translation (object stays “pinned”; others move relative to it).</p>
