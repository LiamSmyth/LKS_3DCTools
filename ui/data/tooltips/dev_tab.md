<p><b>Dev Tab</b></p>
<p>Development and debugging tools for LKS module authors.</p>
<p><span style='color:#90caf9;'>Dev Mode:</span> When enabled, action scripts reload all LKS modules before executing. Useful for development but adds ~1s per invocation.</p>
<p><span style='color:#ffb74d;'>⚠️ Disable for production</span> use and fast radial menus.</p>
<p><span style='color:#90caf9;'>Reload Modules:</span> Hot-reload without restarting 3DCoat.</p>
<p><span style='color:#90caf9;'>Extension Info:</span> Inspect paths, loaded modules, and action scripts.</p>
