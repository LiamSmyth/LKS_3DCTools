<p><b>Voxelize (preprocess)</b> — Voxelize the <span style='color:#90caf9;'>sculpt source</span> before autopo runs. This is a preprocess step on the input mesh, not a conversion of the retopo result.</p>
<p>To bring the retopo mesh into the sculpt room after autopo, use <span style='color:#90caf9;'>Autopo → Sculpt</span>.</p>
