<p><b>Hotkey Editor</b></p>
<p>Manage keyboard shortcuts for <span style='color:#90caf9;'>LKS tools</span>. Launch the standalone editor to modify hotkey assignments.</p>
<p><span style='color:#ffb74d;'>⚠️ Important:</span> Launching the editor closes 3DCoat because 3DCoat saves its in-memory hotkey state on exit, which would overwrite any edits made while it's running.</p>
