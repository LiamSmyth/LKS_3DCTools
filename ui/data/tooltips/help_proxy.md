<p><b>Display proxy (decimated) or cached representations</b> of sculpt objects for faster viewport performance.</p>
<p><span style='color:#90caf9;'>Proxy Mode</span> — select reduction multiplier (Decimate 2x/4x/8x/16x, Reduce 2x/4x/8x)<br>
<span style='color:#90caf9;'>Set Proxied</span> — enable proxy on unproxied objects<br>
<span style='color:#90caf9;'>Set Unproxied</span> — disable proxy on proxied objects<br>
<span style='color:#90caf9;'>Toggle</span> — flip proxied/unproxied state per scope</p>
<p><span style='color:#90caf9;'>Cache Buttons</span> — persist proxy state to disk (Cache Visible / Uncache Visible / Clear All Caches).</p>
<p>Use scope icons (Selected / Subtree / All) on each proxy row.</p>
