<p><b>Configure and run automatic retopology</b> (quadrangulation) on selected sculpt objects.</p>
<p><span style='color:#90caf9;'>Preprocess</span> — optional <b>Voxelize</b> and <b>Decimate if above</b> on the sculpt source <i>before</i> autopo (not on the retopo result)<br>
<span style='color:#90caf9;'>Polycount</span> — target polygon count (logarithmic, 100–100,000)<br>
<span style='color:#90caf9;'>Capture Details</span> — how much surface detail to preserve<br>
<span style='color:#90caf9;'>Auto Density</span> — influence of painted density maps (UI 0–100% ↔ API 0.0–2.0)<br>
<span style='color:#90caf9;'>Quality</span> — Draft / Intermediate / Best</p>
<p><span style='color:#90caf9;'>Skip Dialog</span> skips the density painting dialog for faster batch workflows.</p>
<p>Click <span style='color:#90caf9;'>Run</span> for basic autopo, <span style='color:#90caf9;'>Autopo → Sculpt</span> to import the result into the sculpt room, or <span style='color:#90caf9;'>Autopo → Multires</span> for a multiresolution import. Use <span style='color:#90caf9;'>Delete Retopo</span> / <span style='color:#90caf9;'>Delete All Retopos</span> to clean retopo objects afterward.</p>
