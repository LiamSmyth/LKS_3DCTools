<p><b>Why does 3DCoat close?</b></p>
<p>3DCoat saves its in-memory hotkey configuration when it exits. If the editor modifies the hotkey file while 3DCoat is running, the changes would be overwritten on exit.</p>
<p><b>Workflow:</b></p>
<ol>
  <li><span style='color:#90caf9;'>Launch</span> the Hotkey Editor (3DCoat closes)</li>
  <li><span style='color:#90caf9;'>Edit</span> your hotkey assignments</li>
  <li><span style='color:#90caf9;'>Save</span> changes in the editor</li>
  <li><span style='color:#90caf9;'>Close</span> the editor</li>
  <li><span style='color:#90caf9;'>Restart</span> 3DCoat (changes will be loaded)</li>
</ol>
