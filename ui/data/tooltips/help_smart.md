<p><b>Miscellaneous mesh operations</b> for scene management.</p>
<p><span style='color:#90caf9;'>ID Map (Tree)</span> — fill subtree with random ID colors for baking<br>
<span style='color:#90caf9;'>Smart Split</span> — voxel: split hidden area into new objects; surface: split masked/frozen area and close holes<br>
<span style='color:#90caf9;'>Safe Symmetrize</span> — remesh + symmetrize selection<br>
<span style='color:#90caf9;'>Merge Parts</span> — merge subtree while preserving part separation<br>
<span style='color:#90caf9;'>Mesh↔Vox</span> — toggle between surface and voxel modes in place</p>
