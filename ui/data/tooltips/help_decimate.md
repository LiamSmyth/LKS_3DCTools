<p><b>Reduce polygon count</b> of sculpt objects to improve performance or match detail levels across a scene.</p>
<p><span style='color:#90caf9;'>Quick</span> — one-click presets (50%, 80%, 1k–1M) for fast results<br>
<span style='color:#90caf9;'>Reduction Slider</span> — dial in a custom percentage from 5–95%<br>
<span style='color:#90caf9;'>Polycount Slider</span> — reduce to an exact target from 100–10M (logarithmic)<br>
<span style='color:#90caf9;'>Match Density to Selection</span> — unify detail via smart decimate/subdivide against the active selection</p>
<p>Use scope icons (Selected / Subtree / All) to choose which objects are affected.</p>
