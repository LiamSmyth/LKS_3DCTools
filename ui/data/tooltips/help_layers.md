<p><b>Manage sculpt layers</b> — clean up, set up, or consolidate the layer stack.</p>
<p><span style='color:#90caf9;'>Setup</span> — creates standard <code>Layer 0</code> (sculpt/depth) + <code>Layer1</code> (color) layers <span style='color:#81c784;'>(non-destructive)</span><br>
<span style='color:#90caf9;'>Cleanup Empty</span> — removes empty layers, then selects Layer 0 <span style='color:#81c784;'>(non-destructive)</span><br>
<span style='color:#90caf9;'>Consolidate</span> — flattens all layers into Layer 0 + Layer1 <span style='color:#ffb74d;'>(⚠️ destructive — cannot undo)</span></p>
