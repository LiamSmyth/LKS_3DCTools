<p><b>Resize sculpt objects</b> by a scale multiplier in <span style='color:#90caf9;'>world space</span>.</p>
<p><span style='color:#90caf9;'>Pivot</span> — World origin (default) or selection world position<br>
<span style='color:#90caf9;'>Quick Scale</span> — ×0.1, ×0.5, ×2, ×10<br>
<span style='color:#90caf9;'>Custom Scale</span> — logarithmic slider 0.01x–100x</p>
<p>Choose a <b>scope</b> via icons: Selected, Subtree, or All. Quick Scale uses subtree. Every sculpt object in scope is updated.</p>
