<p><b>Control object visibility and ghost states</b> in the viewport.</p>
<p><span style='color:#90caf9;'>Visibility</span> — Hide or show objects by scope<br>
<span style='color:#90caf9;'>Ghost</span> — Make objects translucent and non-interactive for reference</p>
<p><span style='color:#90caf9;'>Invert / Toggle Isolate</span> — bulk state flips to quickly switch between working on one object vs seeing everything.</p>
<p>Use scope icons (Selected / Subtree / All) on each row.</p>
