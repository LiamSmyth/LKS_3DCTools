<p><b>Create, configure, and apply voxel boolean operations.</b></p>
<p><span style='color:#90caf9;'>Create child</span> — clone the selected object as a boolean child (Union / Subtract / Intersect). The original becomes the parent.<br>
<span style='color:#90caf9;'>Set Mode</span> — change boolean mode on existing objects in-place. Auto-voxelises both the element and its parent.<br>
<span style='color:#90caf9;'>Apply</span> — collapse a boolean subtree, merging children into the parent.<br>
<span style='color:#90caf9;'>Apply (keep)</span> — collapse on a duplicate, hiding the original.</p>
<p><span style='color:#ffb74d;'>⚠️ Voxelization:</span> Both Create child and Set Mode convert objects to voxels, which is required for boolean operations.</p>
