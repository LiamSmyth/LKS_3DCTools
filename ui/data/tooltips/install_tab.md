<p><b>Install Tab</b> — add LKS tools as <b>custom Scripts-menu items</b> so they can be hotkey-mapped in 3DCoat Preferences.</p>
<p>This does <b>not</b> install 3DCoat itself or pip packages. It only registers LKS action scripts and radial menus into the Scripts menu (plus matching prefs XML under <code>UserPrefs/Scripts/ExtraMenuItems/</code>).</p>
<p>After uninstall, restart 3DCoat if the Scripts menu still shows old entries.</p>
