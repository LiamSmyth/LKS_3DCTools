<p><b>Match Density to Selection</b> — Smart-match polygon density against the selected reference, using <span style='color:#90caf9;'>resample</span> when downsampling (not decimate).</p>
<p>Objects outside the reference are adjusted proportionally with a small tolerance so near-matches are skipped. Use the Decimate section’s Match Density for the decimate-based smart path instead.</p>
