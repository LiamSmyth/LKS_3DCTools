<p><b>Tools Tab</b></p>
<p>Configure and apply sculpt operations via collapsible sections. Each section has its own <b>?</b> help button with detailed usage notes.</p>
<p><b>Scope icons</b> — determine which objects each operation targets:</p>
<ul>
  <li><b>☝️ Selected</b> — the currently selected sculpt object(s)</li>
  <li><b>🌳 Subtree</b> — the selected object and all its children</li>
  <li><b>🌎 All</b> — every sculpt object in the scene</li>
</ul>
<p><b>Special icons:</b></p>
<ul>
  <li><b>🔄 Invert</b> — flips the current state (visible ↔ hidden, ghosted ↔ unghosted)</li>
  <li><b>Toggle Isolate</b> — alternates between isolated and full view</li>
</ul>
