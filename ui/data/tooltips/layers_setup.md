<p><b>Setup Standard Layers</b> — Creates the standard 2-layer setup for sculpting.</p>
<p><span style='color:#90caf9;'><b>Layer 0</b></span> — named <code>Layer 0</code> (depth / sculpt layer, 100% opacity)<br>
<span style='color:#90caf9;'><b>Color layer</b></span> — named <code>Layer1</code> (vertex colors, 100% opacity; matches 3DCoat paint default)</p>
<p><i>Non-destructive: existing layers are preserved. Legacy <code>Layer 1</code> is renamed to <code>Layer1</code> on setup.</i></p>
