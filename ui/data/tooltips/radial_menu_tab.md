<p><b>How to create a hotkey-mapped radial menu</b></p>
<p><span style='color:#90caf9;'>1. Create the menu:</span><br/>
• Click <b>New</b> for a starter menu with a unique library name<br/>
• Or design the tree below (items, icons, actions)<br/>
• Hold <b>Preview Radial</b> to try the pie without running actions</p>
<p><span style='color:#90caf9;'>2. Save to library:</span><br/>
• New already stores the menu in the library<br/>
• Use Save / Save As to keep further edits</p>
<p><span style='color:#90caf9;'>3. Install as a menu entry:</span><br/>
• Select your menu from the library dropdown<br/>
• Click <b>Install</b> here (or use Install tab → Radial Menus)<br/>
• New installs usually appear in Scripts immediately; <b>restart 3DCoat</b> mainly after uninstall or when disk and the live Scripts menu disagree</p>
<p><span style='color:#90caf9;'>4. Assign a shortcut:</span><br/>
• Scripts menu → find <code>LKS: RadialMenu_&lt;name&gt;</code><br/>
• Hover the item and press your shortcut key<br/>
• Or: Preferences → Hotkeys → Scripts</p>
<p><span style='color:#ffb74d;'>To uninstall:</span><br/>
• Select the menu → <b>Uninstall</b><br/>
• Restart 3DCoat if the Scripts entry still shows<br/>
• For library ↔ registry batch sync, use Install tab → <b>Sync All</b></p>
