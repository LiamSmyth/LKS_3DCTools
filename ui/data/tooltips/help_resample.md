<p><b>Change polygon count</b> by scaling, matching, or targeting exact values.</p>
<p><span style='color:#90caf9;'>Half / Double</span> — quick 0.5x or 2x rescaling per scope<br>
<span style='color:#90caf9;'>Match Density to Selection</span> — smart-match with resample downsampling against the selected reference<br>
<span style='color:#90caf9;'>Target Polycount</span> — set an exact polygon count per object<br>
<span style='color:#90caf9;'>Target Density</span> — uniform world-space detail in tris/unit²</p>
<p><span style='color:#ffb74d;'>⚠️ Check the estimate readout</span> below the sliders — it shows total polycount across all visible objects and warns at high values.</p>
<p>Use scope icons (Selected / Subtree / All) to choose which objects are affected.</p>
