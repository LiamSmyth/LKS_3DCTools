<p><b>Convert sculpt objects</b> between <span style='color:#90caf9;'>Surface</span> (polygon) and <span style='color:#90caf9;'>Voxels</span> (volume) representation.</p>
<p><span style='color:#90caf9;'>Surface mode</span> — polygon-based editing, decimation, quadrangulation<br>
<span style='color:#90caf9;'>Voxel mode</span> — boolean operations, volume sculpting, resampling</p>
<p><span style='color:#ffb74d;'>⚠️ Note:</span> Surface objects with corrupted topology may need a pre-resample before conversion to voxels.</p>
<p>Use scope icons (Selected / Subtree / All) on each row.</p>
