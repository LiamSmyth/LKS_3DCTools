<p><b>Auto Density</b> — How strongly painted density maps influence retopology.</p>
<p>The slider shows <span style='color:#90caf9;'>0–100%</span>; that maps to the 3DCoat API range <span style='color:#90caf9;'>0.0–2.0</span> (100% = 2.0). Higher values follow painted density more strongly; lower values reduce its influence. Default mid-low values (~25% ≈ 0.5) are a light influence.</p>
