# Radial Menu Library

This directory contains saved radial menu configurations that can be loaded via the LKS Tools panel.

## Structure

Each `.json` file in this directory represents a radial menu configuration that appears in the library dropdown.

## Creating Library Items

1. Design your radial menu in the Radial tab
2. Click "📥 Store to Library"
3. Enter a name for the preset
4. The configuration is saved to this directory

## Loading Library Items

1. Select a menu from the Library dropdown
2. Click "📖" button to load it

## Deleting Library Items

1. Select the menu to delete from the Library dropdown
2. Click "🗑️ Delete" button
3. Confirm the deletion
