<span style="color:#90caf9;">**Tools**</span> — Collapsible sections for decimate, resample, mode convert, boolean, scale, visibility, ghost, autopo, subdiv, and layers. Every operation can target Selected, Subtree, or All objects.

<span style="color:#ce93d8;">**Radial**</span> — Design your own radial pie menus. Build a tree of actions, save to the library, and install as a hotkey.

<span style="color:#81c784;">**Hotkey**</span> — Launch the standalone hotkey editor to manage keybindings. Closes 3DCoat so hotkey changes aren't overwritten.

<span style="color:#ffb74d;">**Install**</span> — Register action scripts and radial menus as 3DCoat menu entries for hotkey assignment. Includes batch install/uninstall and menu cleanup tools.

<span style="color:#4fc3f7;">**Dev**</span> — Development tools: toggle hot-reload mode, reload modules without restarting 3DCoat, inspect paths and discovered action scripts.

<span style="color:#90caf9;">**Outliner**</span> (left sidebar) — Hierarchical scene object tree with visibility, ghost, and polycount columns. Click to select; drag the handle to resize.

<span style="color:#ffb74d;">**Log**</span> (right sidebar) — Timestamped activity log. Shows results of every operation. Click the ribbon to collapse.
