**Radial menus** let you invoke <span style="color:#ffb74d;">multiple tools from a single hotkey</span>. When triggered, a pie menu appears at your cursor — hover over an item and release to execute that action.

<span style="color:#90caf9;">**Bundled menus:**</span> The addon ships with pre-configured radial menus that cover common workflows. You can also create your own in the <span style="color:#90caf9;">**Radial**</span> tab.

1. Open the <span style="color:#90caf9;">**Install**</span> tab and expand the <span style="color:#90caf9;">**Radial Menus**</span> section (or use **Install** on the Radial tab for the menu you have open).
2. Click <span style="color:#ffb74d;">**Install**</span> next to each bundled menu you want to use.
3. New installs usually appear in the <span style="color:#90caf9;">**Scripts**</span> menu immediately. <span style="color:#ffb74d;">**Restart 3DCoat**</span> mainly after uninstall, or when the Scripts menu still disagrees with what you installed/uninstalled on disk.
4. Open <span style="color:#90caf9;">**Scripts**</span> and find the entry (e.g. *LKS: RadialMenu_Main*). Hover + press a key to assign a shortcut — or use Preferences → Hotkeys → Scripts.
5. Press that shortcut in the viewport to open the radial menu.

<span style="color:#ffb74d;">**TIP:**</span> The **Sync All** button in the Install tab compares your library with what's registered and automatically installs new menus or removes stale ones.
