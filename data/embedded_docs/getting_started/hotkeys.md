To assign a keyboard shortcut to any LKS tool, you must first <span style="color:#ffb74d;">**install**</span> it as a menu entry. The installed scripts appear in 3DCoat's <span style="color:#90caf9;">**Scripts**</span> dropdown menu, where you can then bind a hotkey using 3DCoat's native shortcut system.

1. Open the <span style="color:#90caf9;">**Install**</span> tab in this panel.
2. Expand the <span style="color:#90caf9;">**Action Scripts**</span> section to see every available tool.
3. Click <span style="color:#ffb74d;">**Install**</span> next to any tool you want to hotkey, or click <span style="color:#ffb74d;">**Install All**</span> to register everything at once.
4. New installs usually show up in <span style="color:#90caf9;">**Scripts**</span> right away. <span style="color:#ffb74d;">**Restart 3DCoat**</span> when an uninstall (or cleanup) leaves a stale Scripts entry, or when the Install tab warns that disk and the live menu disagree.
5. Open 3DCoat's <span style="color:#90caf9;">**Scripts**</span> menu. Hover over the tool name (e.g. *LKS: …*) and press your desired shortcut key. 3DCoat saves hotkeys automatically on exit.

<span style="color:#ffb74d;">**TIP:**</span> Only install the scripts you actually use as hotkeys. The **Install All** button is convenient, but it may clutter your Scripts menu. Use **Uninstall** to remove individual entries when needed.
