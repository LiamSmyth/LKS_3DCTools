<span style="color:#ffb74d;">**Collapse sections**</span> you don't use — the panel remembers which sections are expanded across sessions.

<span style="color:#ffb74d;">**Drag to reorder sections**</span> — use the grip handle on the left of each collapsible section in the Tools tab to rearrange them.

<span style="color:#ffb74d;">**Resize side panes**</span> — drag the thin handle between the outliner/tabs or between tabs/log to adjust panel widths.

<span style="color:#ffb74d;">**Pin the panel**</span> — the pin button in the footer keeps the panel above other windows.

<span style="color:#ffb74d;">**Log pane**</span> — click the side ribbon to expand/collapse it. Use Copy to grab log text, Clear to wipe it.

<span style="color:#90caf9;">**Dev Mode**</span> — when enabled, action scripts reload all Python modules before executing (adds ~1s). Useful while developing custom tools; leave off for production.
