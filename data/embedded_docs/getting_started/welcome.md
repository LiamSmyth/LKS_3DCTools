LKS Tools is a **sculpting productivity addon** for <span style="color:#90caf9;">3DCoat</span>. It provides a panel of mesh operations — <span style="color:#ffb74d;">decimate, resample, mode convert, booleans, and more</span> — that you can apply by clicking buttons or assigning to hotkeys.

Most tools operate on a **scope**: <span style="color:#90caf9;">Selected</span> / <span style="color:#90caf9;">Subtree</span> / <span style="color:#90caf9;">All</span>. Click the **?** in any tab header for an explanation of the scope icons and what each operation does.
